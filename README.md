# 顔認識落ち物回避ゲーム

## 概要
OpenCVによる顔認識を利用して操作する落ち物回避ゲームです。
プレイヤーの顔位置を検出し、左右移動によって落下物を避けます。

## 開発期間
1週間

## 開発人数
1名

## 使用技術
- Python
- OpenCV
- NumPy

## 機能
- リアルタイム顔認識
- 顔位置によるプレイヤー操作
- ランダムな障害物生成
- スコア計測
- 当たり判定

## 工夫した点
OpenCVの顔認識機能を利用し、キーボードを使わず顔の位置だけで操作できるゲームを開発した。
また、複数の障害物を異なる速度で落下させることでゲーム性を向上させた。
